# Code of Conduct

Everyone participating in this project should be treated with respect, regardless of experience, identity, disability, nationality, religion, or background. This applies to issues, pull requests, reviews, discussions, and other project spaces.

Discuss ideas and implementation choices directly and constructively. Give useful context, accept good-faith corrections, respect boundaries, and keep disagreement focused on the work. Do not harass, threaten, discriminate, publish private information, use sexualized language toward participants, or repeatedly disrupt a discussion.

Maintainers may edit or remove inappropriate content, close discussions, restrict participation, or exclude participants according to the severity and repetition of the behavior. They should apply these expectations consistently and protect the privacy of people reporting concerns.

Report a concern privately to a repository maintainer through an available private contact channel. If none is listed, request a private contact channel without posting personal details or allegations publicly. Do not send a report to a person involved in the concern when another maintainer is available. Maintainers should acknowledge reports, review the context, and explain any action to the affected parties when appropriate.
